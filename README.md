# Residential-house-planning
Residential house planning using AutoCAD for 30×90 ft, 60×40 ft and 30×30 ft plots.
## Project Overview
Residential house planning projects prepared using AutoCAD.

## Plot Sizes
- 30 × 90 ft
- 60 × 40 ft
- 30 × 30 ft

## Work Done
- Prepared 2D residential floor plans
- Space planning and room layout
- Basic dimensioning and drafting
- Prepared section and elevation drawings

## Software Used
- AutoCAD
